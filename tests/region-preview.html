A Paper About Reading

Local demonstration · No external API

Abstract

Reading brings ideas closer. Translate only the region you need. Keep formulas and citations unchanged [1]. This paragraph is a local fixture for checking the selection overlay and its typography.

1. Introduction

The translation should appear where you selected the text. A simple paper background can be covered by a matching surface, while complex illustrations are better served by a readable card.

A dark reading region uses light text. Closing the overlay reveals the unchanged original content.

2. Results

Use Escape to cancel. Scroll the document to dismiss the old overlay. Scrolling inside a result card should keep it open.
