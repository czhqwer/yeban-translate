## 二、详细说明

以下内容可复制到“详细说明”字段：

```text
页伴翻译是一款面向 Chrome 和 Edge 电脑端的轻量网页翻译扩展。它保留网页原文，在相邻位置展示译文，让阅读外语文章、博客和技术文档时可以自然对照。

主要功能：
• 网页双语：翻译当前已展开的网页正文，并保留原文对照。
• 划词翻译：选中文字后，由用户点击翻译按钮查看译文。
• 悬浮入口：在已授权的网站快速开始整页翻译或打开侧栏。
• 文本侧栏：输入或粘贴文本，在浏览器原生侧栏中完成中英互译。
• 服务选择：支持配置自己的百炼大模型或阿里云机器翻译服务，并设置优先级。
• 权限可控：可以只授权当前网站，也可以主动开启全部普通网站；随时可以停用网站或撤销权限。

数据与费用说明：
• 服务凭据和偏好只保存在本机扩展存储中，不进行云同步。
• 只有在用户主动发起翻译时，待译文本和必要的鉴权信息才会通过 HTTPS 直接发送至所选阿里云官方服务。
• 页伴翻译不运营中转服务器，不记录浏览历史或翻译历史，不接入广告和追踪服务。
• 扩展本身免费；所选翻译服务可能根据用户自己的账户和用量收费。

使用前需要在设置页阅读数据使用说明，并配置至少一个自己有权使用的翻译服务。网页翻译适用于普通 HTTP / HTTPS 页面；浏览器内部页、扩展商店等受限页面无法注入扩展脚本。
```

## 三、Privacy practices：单一用途

填写到“Single purpose description”：

```text
在用户主动操作或授权的网站上，将网页或输入文本发送至用户选择的阿里云官方翻译服务，并以双语网页、划词浮窗或浏览器侧栏形式展示译文。
```

## 四、Privacy practices：权限理由

### activeTab

```text
用户点击扩展工具栏按钮并发起操作时，临时取得当前标签页权限，用于读取需要翻译的当前页面内容、注入本地翻译脚本并展示译文。该权限不会让扩展在用户未操作时持续访问所有标签页。
```

### scripting

```text
用于在用户当前页面或用户已明确授权的网站中注入随扩展一同打包的本地内容脚本，实现网页文本发现、双语译文展示、划词按钮和悬浮入口。扩展不下载或执行远程代码。
```

### storage

```text
用于在本机保存用户选择的语言、服务优先级、翻译服务配置、数据使用确认状态、已启用网站规则和悬浮入口位置；并在会话存储中保存临时任务与侧栏状态。不使用 Chrome 同步存储，不保存翻译历史。
```

### sidePanel

```text
用于打开浏览器原生侧栏，提供用户输入或粘贴文本的翻译界面，并同步侧栏的打开和关闭状态。
```

### 主机权限：阿里云官方接口

```text
用于从扩展后台通过 HTTPS 直接调用用户选择并自行配置的百炼或阿里云机器翻译官方接口。待译文本和必要的鉴权信息不经过扩展开发者服务器，主机范围限制为扩展当前支持的官方服务域名。
```

### optional_host_permissions：http://*/* 和 https://*/*

```text
用于在用户主动授权的普通网站提供持续的划词翻译、悬浮入口和网页翻译工具。用户可以只授权当前网站；只有用户明确点击“在所有网站启用”并接受浏览器权限提示后，才会取得全部普通网站权限。浏览器受限页面不在功能范围内，权限可随时撤销。
```

## 六、Privacy practices：数据类型与用途

基于当前实现，至少申报以下数据类型：

### Website content（网站内容）

```text
当用户主动发起整页翻译或点击划词翻译按钮时，扩展处理相应的网页文字；侧栏翻译处理用户主动输入或粘贴的文本。待译文本仅用于取得并展示翻译结果，不由扩展开发者保存。
```

### Authentication information（身份验证信息）

```text
用户自行填写所选翻译服务的 API Key 或 AccessKey。凭据保存在本机扩展存储中，只用于直接鉴权用户选择的官方翻译服务，不提供给访问的网页或扩展开发者。阿里云 AccessKey Secret 仅在本机用于计算请求签名，不以明文发送。
```

当前实现不记录用户访问过的网页，不建立浏览历史，因此不申报 Web history。如果发布前加入 URL 日志、网站使用统计、分析 SDK 或类似功能，必须重新评估并更新申报。

数据用途选择“提供扩展核心功能”。根据当前实现，可以确认以下 Limited Use 声明：

- 不向第三方出售用户数据；仅在提供用户主动请求的翻译功能所必需时，将待译文本和鉴权信息发送给用户选择的阿里云官方服务。
- 不将用户数据用于与扩展单一用途无关的目的。
- 不将用户数据用于信用评估、借贷或广告画像。
- 扩展开发者不接收翻译内容，也不提供可供开发者人员读取翻译内容的后台。

隐私政策字段填写：

```text
https://czhqwer.github.io/yeban-translate/privacy-policy.html
```

## 八、Test instructions

以下内容可复制到审核测试说明：

```text
本扩展没有开发者运营的登录系统。用户需要配置自己有权使用的百炼或阿里云机器翻译凭据，扩展才会向相应官方服务发起真实翻译请求。

测试步骤：
1. 安装扩展后点击工具栏中的“页伴翻译”，点击齿轮进入设置页。
2. 阅读“数据使用说明”，点击“我了解并同意发送待译文本”。未经确认时，扩展会拒绝所有真实翻译请求。
3. 在“翻译服务”中配置一个服务，保存后可点击“测试连接”。测试连接会发送固定示例文本，可能产生服务用量。
4. 打开一个普通 HTTP / HTTPS 文章页面，点击扩展图标。可以使用 activeTab 临时权限执行“翻译当前页面”；也可以主动为当前网站授权，以启用划词翻译和悬浮入口。
5. 选中普通正文中的文字，点击选区右侧出现的翻译图标，检查划词译文浮窗。
6. 点击悬浮入口或扩展侧栏按钮，打开文本翻译侧栏，输入不超过 2000 个字符的测试文本并翻译。
7. 在设置页停用网站或在浏览器扩展管理页面撤销网站权限，相关网页工具应停止工作。

浏览器内部页、Chrome Web Store、其他扩展页面等受限页面无法注入脚本，这是浏览器平台限制。
```

如果审核方必须验证真实翻译，发布者可在开发者后台的私密测试字段中手动填写专门创建的低权限、低额度、可随时撤销的测试凭据。不要把凭据写进本文件、源码、ZIP、截图或公开商店说明。
