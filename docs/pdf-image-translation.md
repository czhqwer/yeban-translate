# PDF 与选区翻译验收（0.4.7）

## 使用方式

1. 设置页配置百炼。默认模型为 `qwen3-vl-plus`，所有图片请求直接使用此配置；无需再次选择模型。旧默认 `qwen-plus` 一次性迁移，其他自定义值保留。
2. PDF 右键“使用页伴翻译选中文字”：新选区自动替换侧栏输入，停止旧任务；旧响应不得覆盖新结果。超过 2000 字符时提示缩小范围。
3. 按 `Alt+Shift+S`：十字框选，左键松开后自动翻译。选框和提示先隐藏两帧，后台完成截图后恢复原位加载，模型返回后原位展示。
4. 纯色背景尽量匹配底色和字色；复杂背景、窄区域或译文过长时使用可滚动卡片。复制、查看原文、关闭都由用户操作。原文件和原 DOM 均不修改。
5. 系统截图可在现有文本侧栏 Ctrl+V 粘贴，显示小附件，点击翻译才发送。没有独立图片页面或图片模型选择框。

## 浏览器边界

只尝试顶层文档，不注入受保护的 PDF 扩展帧。原生 PDF 阅读器若拒绝顶层注入，无法出现十字框选或原位覆盖；此时扩展图标显示“!”，工具栏/侧栏提示使用系统截图粘贴，不创建新标签页。内置 PDF 阅读模式仍未实现。
本地文件需允许文件网址访问。快捷键冲突可在浏览器扩展快捷键页修改。

## 数据和会话

- 框选会话只能由原生快捷键、菜单或可信工具栏创建；绑定浏览器提供的 tabId、documentId、顶层 frameId 和随机 token。普通网页不能自行请求截图。
- 同一个会话只能提交一次选区；后台检查有限坐标、范围、视口大小与滚动位置。截图前后和请求前后都复查活动标签与文档。
- 整屏位图仅存在于后台内存；通过 OffscreenCanvas 按实际截图像素比例裁剪，只有选区图像进入模型。不把整屏位图放入网页、URL、日志或存储。
- 图片重新编码后限制 4 MB、4096 像素边长及 1000 万像素。取消、导航、切页和权限撤销使会话失效；晚到响应丢弃。不自动重试。
- 模型读取已保存的百炼配置，沿用服务队列、版本检查、取消信号和端点白名单。网页不得指定或获取模型凭据。输出始终以纯文本显示。
- 松开框选即表示开始发送选区；粘贴只预览、点击翻译才发送。请求已提交后，停止不能撤回服务用量。

## 验证记录

- 已通过 TypeScript 检查和自动测试。测试仅使用虚拟数据，无真实 API 调用。
- 自动覆盖正反向框选、合成事件拒绝、原位加载、转为卡片、滚动卡片不关闭、Esc 取消、迟到响应隔离、高 DPI 裁剪、页面切换/缩放、模型一次性迁移和右键自动替换。
- 原生 Chrome/Edge PDF 框选仍需在各阅读器版本中手动确认；单元测试不证明受保护 PDF 可注入。真实百炼识别质量未验收。
- Chrome 本地模拟页面已验证十字框选、松开后原位译文、查看原文、关闭以及侧栏选区自动载入。原生 PDF 的自动化访问超时，未完成真实阅读器注入验收。
- 本地模拟验收：`npm run build` 后运行 `node tests/preview-server.mjs`，访问 `http://127.0.0.1:4177/region-preview.html`、`/sidepanel.html?reading=text` 或 `/options.html`。模拟页不捕获屏幕或发送外部请求。

## 手动验收清单

- 普通网页、网页 PDF 阅读器、原生在线/本地 PDF：可注入时框选有效，拒绝时无新页面且提示准确。
- 高 DPI、浏览器缩放、反向拖动、边缘选区：发送范围与框选一致；触控缩放时提示先退出。
- 未配置百炼/未确认说明：只显示引导，不截图上传。
- 文本与图片采用设置中的同一模型；旧默认一次迁移，自定义配置不被后续启动覆盖。
- 滚动原页关闭旧覆盖，滚动译文保留卡片；停止、重选、切页后旧结果不出现。
- 右键第二次选区直接载入；图片粘贴不跳转、普通文字粘贴正常。
- 模型的地域可用性、公式与引用准确性由用户使用自己的服务验证。
