# 页伴翻译

一页双语，随手即译。

页伴翻译是面向 Chrome / Edge 电脑端的轻量扩展，当前版本为 0.2.4，支持网页双语、点击划词、可拖动悬浮入口和原生文本翻译侧栏。使用者配置自己的百炼或阿里云机器翻译服务，无须部署独立后台。

## 安装本地体验版

1. 将 `release/yeban-translate-0.2.4.zip` 解压到一个固定目录；也可以直接使用项目中的 `dist/` 目录。基础能力要求 Chrome 116 或更新版本；完整侧栏开关建议 Chrome 142 或更新版本。Edge 按实际侧栏接口能力适配。
2. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`。
3. 开启开发者模式，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录。
4. 将“页伴翻译”固定到浏览器工具栏，点击齿轮进入设置。
5. 阅读文本发送说明，并配置至少一个翻译服务。凭据只由你在扩展设置页填写，不需要放入项目文件或发送给开发助手。

源码修改后重新构建，再在扩展管理页点击重新加载，并刷新此前已打开的文章页。

### 从已有版本升级

将新包覆盖到原来加载的扩展目录，保留原扩展条目，在扩展管理页点击重新加载；这样可以沿用同一扩展身份下保存的服务配置。浏览器若提示新增侧栏权限，请按提示确认，随后刷新文章页。

更新到 0.2.4 后请刷新原文章页，加载新的划词定位和悬浮拖动逻辑；已经打开的设置页和翻译侧栏可刷新或关闭后重新打开。此补丁沿用已有服务配置与网站授权，不新增权限。

0.2.4 将划词按钮放到选区末行右侧，靠近屏幕边缘时自动避让。侧边两个按钮均支持按住上下拖动，松手后记住位置；刷新或新页面沿用最后保存的位置。

0.2.3 将侧栏压缩为单行页头和两行选择工具栏，减少输入区上方的空间。正常状态只保留必要字段与计数；超长、未配置或失败时再显示提示。设置页为两项服务增加“配置帮助”，费用与隐私说明集中折叠，未确认的新用户仍需明确确认后才能翻译。

0.2.2 将浮球精简为翻译与侧栏两个图标：翻译按钮首次点击翻译当前已展开的整页内容，再次点击停止并恢复原文；侧栏按钮在接口完整的浏览器中切换打开与关闭。划词触发按钮缩为 24px，并修复鼠标点击浮球时出现的大块焦点边框。网页翻译运行期间，展开导航菜单会继续发现新出现的子项；保持折叠的内容不会提前发送。

旧版默认服务会迁移为优先级首项，未配置服务会自动跳过。划词功能默认开启；首次使用新版时可在设置中点击“在所有网站启用划词和悬浮球”，完成一次全站访问授权。拒绝授权不会替用户授予权限，原来有效的逐站授权仍可使用。

## 服务选择与优先级

默认使用“按优先级自动选择”。只配置阿里云机器翻译时会直接选择它；两个服务都配置时，按照设置页中的顺序选择。可以通过上移、下移调整优先级，也可在当前页或侧栏明确选择一个服务。

排序修改只影响后续自动任务；运行中的翻译和失败重试保留原服务。手动选择未配置服务时会提示配置，不静默改选。请求失败不会自动转到另一家服务产生额外调用。

## 使用翻译服务

在设置页对应服务卡片点击“配置帮助”，即可查看获取凭据、字段对应和保存测试步骤。百炼教程说明地域、API Key、完整请求地址与模型的对应关系；机器翻译教程说明开通通用版、RAM 用户授权，以及 AccessKey ID（AK）和 AccessKey Secret（SK）的填写位置。教程包含固定的官方文档入口，支持 × 或 Esc 关闭，打开帮助不会保存表单或发送测试请求。

### 百炼大模型

- 填写官方 OpenAI 兼容 Chat Completions 端点、模型名和 API Key。
- 内置候选模型为 `qwen-plus`；端点必须与开通地域及凭据匹配。
- 支持的主机包括国内、国际及美国 DashScope 域名，以及已列入白名单的百炼工作空间域名；不接受第三方代理地址。
- 先保存，再点击“测试连接”。测试发送固定示例文本，可能计入服务用量。

### 阿里云机器翻译

- 首版接入杭州通用版 `TranslateGeneral`，接口版本 `2018-10-12`，服务端点为 `https://mt.cn-hangzhou.aliyuncs.com`。
- 填写你有权使用且已开通机器翻译的 AccessKey ID 和 AccessKey Secret。
- 请求使用 ACS3-HMAC-SHA256 签名；凭据不会作为网页可访问的数据返回。
- 支持中文、英文以及自动识别源语言；超长正文按字符边界分段处理。

已保存凭据不会回填到输入框；留空保留已有值，填写新值则替换。“删除配置”会删除该服务配置并停止相关任务。

## 网页双语阅读

打开普通文章、博客或技术文档，点击扩展图标，选择服务和语言，再点击“翻译当前页面”。扩展分批处理页面中当前已展开的内容，包括视口之外的正文、导航与表格，无须先滚动到每一段；隐藏或折叠区域不会提前发送。与只翻译视口内容相比，整页翻译可能产生更多 API 调用。

0.2 补齐了表格单元格说明、可见导航标签和父列表文字、带隐藏锚点的标题，以及含行内代码的段落。行内代码先用保护标记参与翻译，结果校验后恢复原字面值；独立代码块、隐藏文字与输入区不送翻译。若服务破坏保护标记，该段会显示失败并允许重试，不将损坏结果作为成功译文。

- **停止翻译**：停止正文队列，保留已有译文。
- **重试失败段落**：只重试失败内容，不重新翻译成功段落；修改服务后请开始新任务。
- **恢复原文**：移除译文与划词浮窗，停止当前文档的两类任务，保留已授权站点的划词偏好。
- 弹窗中的服务和语言仅作用于当前页；默认偏好在设置页保存。当前页选择也用于接下来点击的划词翻译。

## 划词翻译

1. 划词功能默认开启；先完成一次全站授权，或在文章页使用原有的逐站授权入口。
2. 由你在浏览器提示中授予网站访问权限；未授权页面不会被自动监听。
3. 选中单词、短语或句子，点击文字右侧出现的翻译图标按钮（24 × 24px，内部图标 16px）。多行选区跟随最后一行；右侧空间不足时放到右下方或选区上方，极端情况下保留在视口右缘。
4. 在浮窗中查看原文与译文，可复制译文、重试或关闭。

选中文字本身不会发起翻译请求。首版选文上限为 2000 个 Unicode 字符，不处理输入框、可编辑区域、代码或扩展自身的译文。可以在设置页关闭已启用站点；Escape、外部点击或选区滚出视口时收起浮窗。

全局划词开关与网页授权是两个状态：关闭划词后，已获授权网页的悬浮入口仍可使用；禁用某个站点会关闭该站的划词与悬浮入口，保留工具栏手动翻译能力。撤销浏览器权限后，扩展会清理相应注册与失权任务。

## 悬浮入口与文本侧栏

获得网页访问权限后，页面右侧只显示翻译与侧栏两个图标。首次点击翻译图标启动整页翻译，再次点击停止并恢复原文，准备或翻译期间也可恢复。恢复原文后入口保留。停止并保留译文、重试失败段落等操作可从浏览器工具栏弹窗使用。

翻译按钮为 32px，侧栏按钮为 28px，间距 4px。移除“...”入口与常驻说明气泡；错误详情可从工具栏弹窗查看。鼠标点击不再让整个浮球容器获得焦点边框，键盘操作仍保留按钮焦点提示。

按住任一悬浮按钮即可上下拖动整个按钮组，水平位置始终贴右。移动超过 6px 后判为拖动，松手不执行按钮动作；轻点和键盘操作保持原行为。上下保留安全边距，窗口缩放后按比例校正位置。拖动结束只保存一次位置，刷新和新页面沿用；取消拖动会回到拖动前的位置。

位置由后台独立保存为 0～1 的纵向比例，不与翻译服务配置混用，也不增加浏览器权限。若保存失败，当前页面仍保留拖动后的显示位置，并提示刷新后可能回到之前的位置。

点击侧栏图标打开浏览器原生文本翻译侧栏；完整支持关闭接口与打开、关闭事件的浏览器中，再次点击会关闭。同一窗口的标签共享侧栏状态，原生关闭按钮和标签移到其他窗口后都会同步。侧栏支持输入或粘贴文本、自动或手动选择服务、中英语言选择、翻译、复制、停止、清空及按原条件重试。文本上限为 2000 个 Unicode 字符，隐藏或关闭侧栏时取消待处理请求，不自动重放。

完整开关依赖 `sidePanel.close`、`onOpened` 和 `onClosed`，Chrome 142 起具备这些接口；Edge 以运行时检测为准。旧版本入口保持“打开侧栏”，使用原生 × 关闭，之后仍可点击图标重新打开，不用过期的状态假装关闭成功。

若浏览器不支持原生侧栏打开，会显示升级提示；普通工具栏与网页翻译能力仍保留。当前侧栏不包含 PDF、图片或视频翻译。

## 数据与权限

- 凭据与偏好仅在本机扩展存储持久保存，并限制为扩展可信上下文访问；不进行云同步。
- 实际翻译时，必要鉴权信息与待译文本会发送至所选官方服务；不向第三方中转服务器发送，不自动附带所在段落或整页上下文。
- 不记录输入框、浏览路径或翻译历史；已启用站点仅用于管理用户授权的站点规则。
- 已发出的请求即使随后停止，也可能计入服务用量。没有真实账单核算功能。
- 本地扩展存储不是系统密码库。请按自己的浏览器与设备使用规则管理配置。

## 开发与验证

使用 Node.js 24 安装并开发：

```sh
npm ci --ignore-scripts
npm run typecheck
npm test
npm run build
npm run pack:extension
```

生产构建位于 `dist/`，打包产物位于 `release/`。发布包不含测试、模拟服务、个人配置或开发依赖。

`tests/preview-server.mjs` 可以展示本地模拟界面，明确标有“模拟响应”。它用于浏览器交互验收，不连接真实 API，也不能替代扩展权限与实际服务联调。运行前先构建，再执行：

```sh
node tests/preview-server.mjs
```

## 当前验证边界

类型检查、241 项自动测试、构建和本地模拟预览验证通过，详情见 [0.2.4 验证报告](../docs/browser-translation-v0.2.4/verification.md)。本轮在浏览器检查了单行及多行选区右侧入口、双按钮拖动、拖动后正常点击、刷新与新页面位置恢复；跨端测试使用真实内容控制器和后台验证位置保存与恢复。浏览器扩展 API 与翻译响应由测试模拟；实际 Chrome / Edge 扩展加载、原生侧栏行为、真实网站授权以及两个服务的真实连通性和翻译质量，仍需要安装后验证。

首版主要面向普通网页正文，不包含 PDF、图片 OCR、字幕、词典发音、生词本或移动浏览器；复杂动态页面与特殊嵌入内容可能不兼容。
