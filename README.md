# 页伴翻译

一页双语，随手即译。

页伴翻译是面向 Chrome / Edge 电脑端的轻量扩展，当前版本为 0.4.4，支持网页多模式翻译、点击划词、编辑器回写、快捷键悬停翻译、可拖动悬浮入口和原生文本翻译侧栏。使用者配置自己的百炼或阿里云机器翻译服务，无须部署独立后台。

## 安装本地体验版

1. 将 `release/yeban-translate-0.4.4.zip` 解压到一个固定目录；也可以直接使用项目中的 `dist/` 目录。基础能力要求 Chrome 116 或更新版本；完整侧栏开关建议 Chrome 142 或更新版本。Edge 按实际侧栏接口能力适配。
2. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`。
3. 开启开发者模式，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录。
4. 将“页伴翻译”固定到浏览器工具栏，点击齿轮进入设置。
5. 阅读文本发送说明，并配置至少一个翻译服务。凭据只由你在扩展设置页填写，不需要放入项目文件或发送给开发助手。

源码修改后重新构建，再在扩展管理页点击重新加载，并刷新此前已打开的文章页。

### 从已有版本升级

将新包覆盖到原来加载的扩展目录，保留原扩展条目，在扩展管理页点击重新加载；这样可以沿用同一扩展身份下保存的服务配置。浏览器若提示新增侧栏权限，请按提示确认，随后刷新文章页。

更新到 0.4.4 后请在扩展管理页重新加载，并刷新原文章页或笔记页，使内嵌页面也加载新版脚本。已有服务配置、默认语言、网站授权、页面模式和悬停快捷键会继续保留，不新增权限。

0.4.4 支持已授权顶层网站内的同源 HTTP(S) iframe 划词与快捷键悬停，适配有道云笔记将 Markdown 预览、富文本编辑区放在独立子页面中的结构。各子文档独立处理选区与翻译任务，不重复创建浮球，不接管顶层全文翻译或侧栏操作。独立代码块允许用户主动划词后点击翻译；自动页面翻译仍跳过代码块和编辑区。

0.4.3 将划词结果窗的边框与内容滚动拆为独立层，缩小窗口后仍保留稳定留白，内容不会贴住边框或遮挡缩放手柄。侧栏的主滚动条改为隐藏式，滚轮、触控板与键盘滚动不受影响；首次设置提示会直接打开、展开并高亮“数据使用说明”。

0.4.2 统一美化扩展界面与划词结果窗的滚动条和缩放手柄；结果窗使用与设置页一致的米白、墨绿、卡片边框与按钮风格，并适配暗色主题。首次授予单站或全站访问权限后，后台会直接完成状态保存、内容脚本注册和当前页面注入，不再需要第二次点击启用按钮。

0.4.1 的划词与悬停结果窗支持从右下角拖动调整宽高，并在同一页面后续结果窗中沿用该尺寸。完整结果窗随页面滚动离开原选区后会固定在当前视口，不再被自动关闭；尚未点击的小翻译按钮有 1.5 秒离屏宽限，滚回选区即可恢复跟随，持续离屏才会收起。侧栏底部增加“跨过语言，抵达文字本身。”寄语。

0.4.0 的编辑器划词结果窗增加紧凑目标语言选择。对于可写的 `contenteditable`、`textarea` 和普通文本输入框，翻译完成后会显示“替换选中”和“插入译文”；只有用户主动点击按钮才会修改编辑内容，并触发标准输入事件以便编辑器同步。普通网页正文、只读控件和密码框不显示写入按钮。

0.4.0 增加四种页面展示方式：双语对照、仅显示译文、鼠标悬停显示原文、左右对照。恢复原文会清理译文并还原临时隐藏与布局样式；为避免破坏表格、列表和交互标签，复杂结构在左右模式下安全回退为上下对照。

0.4.0 增加独立的鼠标悬停翻译设置。此功能默认关闭；开启并完成网站授权后，将鼠标放在段落上，同时按下设定快捷键，才会读取并翻译该段文字。快捷键默认为 `Alt+I`，可在设置页直接按下新的组合键修改；组合键必须包含 Ctrl、Alt 或 Meta，以避免正常输入误触发。

0.3.0 增加编辑区域划词和智能翻译方向：语雀、钉钉文档等使用 `contenteditable` 或 `role="textbox"` 的富文本编辑区可以翻译明确选中的文字，普通 `textarea` 及非敏感文本输入框只读取选中范围，密码框继续拒绝。中文选区默认翻译为英语，其他语言默认翻译为简体中文；侧栏输入同样自动选择目标语言，用户手动选择后以手动设置为准。

0.3.0 同时将页面翻译改为滚动按需模式：启动时只发送当前视口内容，未读到的屏外段落不产生请求；滚动加载或稍后进入视口的新正文会自动加入翻译。快速滚过且仍在队列中的内容会退回等待状态，避免继续消耗额度。

0.2.9 精简文本侧栏并增加多语互译：侧栏只保留原文与目标语言；简体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语、阿拉伯语、土耳其语、印度尼西亚语、越南语、泰语和波兰语在弹窗、侧栏与设置页统一可选。页面译文颜色由原色约 74% 调整为约 62% 的不透明度。

0.2.8 精简工具栏弹窗：只保留当前页语言和翻译控制。未配置任何服务时在状态区引导打开设置，不显示无效或重复的服务表单。

0.2.7 改进全文译文的富文本还原与辨识度：服务返回的内容仍按纯文本处理，只依据扩展生成且严格校验的内部标记恢复安全节点；标记损坏时整段失败，不展示或缓存不完整结果。

0.2.4 将划词按钮放到选区末行右侧，靠近屏幕边缘时自动避让。侧边两个按钮均支持按住上下拖动，松手后记住位置；刷新或新页面沿用最后保存的位置。

0.2.3 将侧栏压缩为单行页头和两行选择工具栏，减少输入区上方的空间。正常状态只保留必要字段与计数；超长、未配置或失败时再显示提示。设置页为两项服务增加“配置帮助”，费用与隐私说明集中折叠，未确认的新用户仍需明确确认后才能翻译。

0.2.2 将浮球精简为翻译与侧栏两个图标：翻译按钮首次点击翻译当前已展开的整页内容，再次点击停止并恢复原文；侧栏按钮在接口完整的浏览器中切换打开与关闭。划词触发按钮缩为 24px，并修复鼠标点击浮球时出现的大块焦点边框。网页翻译运行期间，展开导航菜单会继续发现新出现的子项；保持折叠的内容不会提前发送。

旧版默认服务会迁移为优先级首项，未配置服务会自动跳过。划词功能默认开启；首次使用新版时可在设置中点击“在所有网站启用划词和悬浮球”，完成一次全站访问授权。拒绝授权不会替用户授予权限，原来有效的逐站授权仍可使用。

## 服务选择与优先级

默认使用“按优先级自动选择”，新安装时阿里云机器翻译排在百炼之前。只配置一种服务时会直接选择它；两个服务都配置时，按照设置页中的顺序选择。服务只在设置页配置和排序，弹窗与文本侧栏只选择语言。

排序修改只影响后续自动任务；运行中的翻译和失败重试保留原服务。请求失败不会自动转到另一家服务产生额外调用。

## 使用翻译服务

在设置页对应服务卡片点击“配置帮助”，即可查看获取凭据、字段对应和保存测试步骤。百炼教程说明地域、API Key、完整请求地址与模型的对应关系；机器翻译教程说明开通通用版、RAM 用户授权，以及 AccessKey ID（AK）和 AccessKey Secret（SK）的填写位置。教程包含固定的官方文档入口，支持 × 或 Esc 关闭，打开帮助不会保存表单或发送测试请求。

### 百炼大模型

- 填写官方 OpenAI 兼容 Chat Completions 端点、模型名和 API Key。
- 内置候选模型为 `qwen-plus`；端点必须与开通地域及凭据匹配。
- 支持的主机包括国内、国际及美国 DashScope 域名，以及已列入白名单的百炼工作空间域名；不接受第三方代理地址。
- 先保存，再点击“测试连接”。测试只发送固定示例文本，不要求先确认网页正文发送说明，但仍可能计入服务用量。

### 阿里云机器翻译

- 首版接入杭州通用版 `TranslateGeneral`，接口版本 `2018-10-12`，服务端点为 `https://mt.cn-hangzhou.aliyuncs.com`。
- 填写你有权使用且已开通机器翻译的 AccessKey ID 和 AccessKey Secret。
- 请求使用 ACS3-HMAC-SHA256 签名；凭据不会作为网页可访问的数据返回。
- 支持自动识别源语言，以及 16 种常用语言的双向组合；超长正文按字符边界分段处理。

已保存凭据不会回填到输入框；留空保留已有值，填写新值则替换。“删除配置”会删除该服务配置并停止相关任务。

## 网页双语阅读

打开普通文章、博客或技术文档，先在设置页选择页面展示方式，再点击扩展图标选择语言和“翻译当前页面”。扩展先处理当前视口中的正文、导航与表格，继续滚动时自动翻译新进入视口的段落；屏外未读内容、隐藏或折叠区域不会提前发送。译文沿用原正文区域的字体、字号、行高、对齐、边框、背景和内边距，并保留链接、粗体、斜体与行内代码等安全结构，不额外显示批注样式；文字颜色使用原色约 62% 的不透明度，便于和原文区分。

- **双语对照**：保留原文，在原区域下方插入译文。
- **仅显示译文**：临时隐藏已经翻译完成的原文；恢复原文时完整还原。
- **悬停显示原文**：平时只显示译文，鼠标悬停或键盘聚焦译文时显示原文预览。
- **左右对照**：普通正文在宽屏上左右各占一半；窄屏与复杂交互结构自动采用安全的上下对照。

0.2 补齐了表格单元格说明、可见导航标签和父列表文字、带隐藏锚点的标题，以及含行内代码的段落。行内代码先用保护标记参与翻译，结果校验后恢复原字面值；独立代码块、隐藏文字与输入区不送翻译。若服务破坏保护标记，该段会显示失败并允许重试，不将损坏结果作为成功译文。

- **停止翻译**：停止正文队列，保留已有译文。
- **重试失败段落**：只重试失败内容，不重新翻译成功段落；修改服务后请开始新任务。
- **恢复原文**：移除译文与划词浮窗，停止当前文档的两类任务，保留已授权站点的划词偏好。
- 弹窗中的语言仅作用于当前页，翻译服务按设置页的最新优先级自动选择；默认语言和服务优先级在设置页保存。划词翻译会独立判断方向：中文默认译为英文，其他语言默认译为中文。

## 划词翻译

1. 划词功能默认开启；先完成一次全站授权，或在文章页使用原有的逐站授权入口。
2. 由你在浏览器提示中授予网站访问权限；未授权页面不会被自动监听。
3. 选中单词、短语或句子，点击文字右侧出现的翻译图标按钮（24 × 24px，内部图标 16px）。多行选区跟随最后一行；右侧空间不足时放到右下方或选区上方，极端情况下保留在视口右缘。中文默认译成英语，其他语言默认译成简体中文。
4. 在浮窗中查看原文与译文，可复制译文、重试或关闭；需要更多阅读空间时，可拖动结果窗右下角调整宽高，同一页面会沿用最后调整的尺寸。

选中文字本身不会发起翻译请求，仍需点击 24px 翻译按钮。结果窗内可用紧凑下拉框切换目标语言，切换时会取消旧任务并重新翻译。选文上限为 2000 个 Unicode 字符；富文本编辑区、普通 `textarea` 和非敏感文本输入框只读取明确选中的片段，译文出现后可主动选择替换或插入。密码框及扩展自身译文始终排除。独立代码块可明确划词后点击翻译，普通段落里的行内代码也可和相邻文字一起翻译；页面翻译仍完全跳过独立代码块、输入框与可编辑区域，不会自动发送未选中的草稿。可以在设置页关闭已启用站点；Escape 或外部点击会主动收起浮窗。滚动时完整结果窗会固定在视口，滚回原选区后重新跟随；未展开的小按钮持续离屏 1.5 秒后才收起，避免快速滚动误关。

同源 HTTP(S) iframe 会在自己的文档内显示划词结果窗，任务按标签页、frame 和 document 独立校验，关闭一个子页面的任务不影响另一个。跨站 iframe、不透明来源及 `about:blank` / `srcdoc` 特殊页面暂未适配。Ace、Monaco 等使用虚拟选区的源码编辑模式也不属于本次兼容范围；有道云笔记可先在 Markdown 预览区选中实际渲染的文字。

## 鼠标悬停翻译

此功能用于替代频繁划词，也可强制处理普通正文识别未覆盖的段落。它与划词开关独立，并且默认关闭：在设置页开启、设置快捷键并授予网站权限后，将鼠标停在目标段落上，再按快捷键即可打开翻译结果窗。仅移动鼠标不会读取或发送文本；密码框、输入控件与扩展自身界面始终排除。悬停结果窗也可以选择目标语言，但不会自动改写网页内容。

全局划词开关与网页授权是两个状态：关闭划词后，已获授权网页的悬浮入口仍可使用；禁用某个站点会关闭该站的划词与悬浮入口，保留工具栏手动翻译能力。撤销浏览器权限后，扩展会清理相应注册与失权任务。

## 悬浮入口与文本侧栏

获得网页访问权限后，页面右侧只显示翻译与侧栏两个图标。首次点击翻译图标启动按滚动翻译，再次点击停止并恢复原文，准备或翻译期间也可恢复。恢复原文后入口保留。停止并保留译文、重试失败段落等操作可从浏览器工具栏弹窗使用。

翻译按钮为 32px，侧栏按钮为 28px，间距 4px。移除“...”入口与常驻说明气泡；错误详情可从工具栏弹窗查看。鼠标点击不再让整个浮球容器获得焦点边框，键盘操作仍保留按钮焦点提示。

按住任一悬浮按钮即可上下拖动整个按钮组，水平位置始终贴右。移动超过 6px 后判为拖动，松手不执行按钮动作；轻点和键盘操作保持原行为。上下保留安全边距，窗口缩放后按比例校正位置。拖动结束只保存一次位置，刷新和新页面沿用；取消拖动会回到拖动前的位置。

位置由后台独立保存为 0～1 的纵向比例，不与翻译服务配置混用，也不增加浏览器权限。若保存失败，当前页面仍保留拖动后的显示位置，并提示刷新后可能回到之前的位置。

点击侧栏图标打开浏览器原生文本翻译侧栏；完整支持关闭接口与打开、关闭事件的浏览器中，再次点击会关闭。同一窗口的标签共享侧栏状态，原生关闭按钮和标签移到其他窗口后都会同步。侧栏支持输入或粘贴文本、多语语言选择、翻译、复制、停止、清空及按原条件重试，翻译服务按设置页优先级自动选择。文本上限为 2000 个 Unicode 字符，隐藏或关闭侧栏时取消待处理请求，不自动重放；内容较少时，底部固定展示产品寄语。

完整开关依赖 `sidePanel.close`、`onOpened` 和 `onClosed`，Chrome 142 起具备这些接口；Edge 以运行时检测为准。旧版本入口保持“打开侧栏”，使用原生 × 关闭，之后仍可点击图标重新打开，不用过期的状态假装关闭成功。

若浏览器不支持原生侧栏打开，会显示升级提示；普通工具栏与网页翻译能力仍保留。当前侧栏不包含 PDF、图片或视频翻译。

## 数据与权限

- 凭据与偏好仅在本机扩展存储持久保存，并限制为扩展可信上下文访问；不进行云同步。
- 实际翻译时，必要鉴权信息与待译文本会发送至所选官方服务；不向第三方中转服务器发送，不自动附带所在段落或整页上下文。输入框与编辑器只发送用户明确划词选中的片段；悬停段落只有在功能已开启且用户按下快捷键后才发送。
- 不记录输入框、浏览路径或翻译历史；已启用站点仅用于管理用户授权的站点规则。
- 已发出的请求即使随后停止，也可能计入服务用量。没有真实账单核算功能。
- 本地扩展存储不是系统密码库。请按自己的浏览器与设备使用规则管理配置。

## 开发与验证

使用 Node.js 24 安装并开发：

```sh
npm ci --ignore-scripts
npm run typecheck
npm test
npm run build
npm run pack:extension
```

生产构建位于 `dist/`，打包产物位于 `release/`。发布包不含测试、模拟服务、个人配置或开发依赖。

`tests/preview-server.mjs` 可以展示本地模拟界面，明确标有“模拟响应”。它用于浏览器交互验收，不连接真实 API，也不能替代扩展权限与实际服务联调。运行前先构建，再执行：

```sh
node tests/preview-server.mjs
```

## 当前验证边界

当前类型检查、289 项自动测试与生产构建均通过。早期浏览器交互检查详情见 [0.2.4 验证报告](../docs/browser-translation-v0.2.4/verification.md)。0.4.4 新增同源 iframe 授权、任务隔离、代码块划词和子文档控制器测试；本地 `/frame-preview.html` 可检查双 iframe 的划词入口与浮球数量。浏览器扩展 API 与翻译响应由测试模拟；实际 Chrome / Edge 扩展加载、复杂富文本编辑器的撤销栈、原生侧栏行为、真实网站授权以及两个服务的真实连通性和翻译质量，仍需要安装后验证。
